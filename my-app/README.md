# Библиотека алгоритмов

Клиент React для REST API проекта. Пользователи хранятся в PostgreSQL, а
алгоритмы вместе с вложенными критериями — в MongoDB Atlas.

## Запуск

1. В корне проекта настройте `.env` для PostgreSQL и JWT:

   ```env
   DATABASE_URL=postgres://user:password@localhost:5432/database
   JWT_SECRET=replace-with-a-long-random-secret
   PORT=3000
   ```

   MongoDB Atlas URI задайте через `MONGODB_URI` в `.env` либо используйте
   предоставленный локальный `atlas-credentials.env`. Не добавляйте реальные
   учетные данные в Git.

2. Установите серверные зависимости, примените миграции PostgreSQL и перенесите
   старые алгоритмы (если таблица еще существует):

   ```bash
   npm install
   npx sequelize-cli db:migrate
   npm run migrate:algorithms
   npm run dev
   ```

   Команда переноса проверяет, что все карточки записаны в MongoDB, и только
   после этого удаляет таблицу `algorithms` из PostgreSQL. После переноса
   PostgreSQL используется только для пользователей.

3. В отдельном терминале запустите клиент:

   ```bash
   cd my-app
   npm install
   npm run dev
   ```

Vite проксирует `/api` на `http://localhost:3000`, поэтому браузеру не требуется
отдельная настройка CORS. Если сервер запущен на другом адресе, задайте
`VITE_DEV_API_PROXY_TARGET` в `my-app/.env`. При необходимости URL API можно
переопределить через `VITE_API_URL` (по умолчанию `/api`).

## Реализовано в лабораторной работе 6

- JWT-регистрация и вход; access/refresh-токены сохраняются в браузере.
- MongoDB CRUD каталога с поиском, индикацией загрузки, сообщением об ошибке и
  кнопкой повтора.
- Добавление, изменение и удаление с оптимистичным обновлением и откатом при
  ошибке сервера.
- До 50 вложенных критериев на алгоритм; длина названия критерия — до 100,
  описания — до 2000 символов. Название алгоритма ограничено 100 символами,
  описание — 1000, поиск — 100;
  имя аккаунта и пароль также проверяются на клиенте и сервере.
- Одно дополнительное улучшение: поиск по названию, типу и описанию выполняется
  на сервере после паузы 350 мс после ввода.
- Компоненты формы, авторизации, списка и карточки алгоритма вынесены в отдельные
  файлы в `src/components`.
